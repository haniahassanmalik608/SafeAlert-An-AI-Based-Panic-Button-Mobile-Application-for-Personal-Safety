# SafeAlert-An-AI-Based-Panic-Button-Mobile-Application-for-Personal-Safety
> SafeAlert is an AI Panic Button Android app for safety. One-tap SOS sends live GPS via SMS to trusted contacts even offline with 5-sec countdown. Integrated Gemini AI gives real-time safety &amp; first-aid guidance. Built for women, students &amp; travelers in Pakistan. Emergency response in 10 seconds.
